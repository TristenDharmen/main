📊 Esports Industry Growth Analysis
Overview
This project delves into the dynamic and rapidly evolving esports industry, analyzing its growth patterns, key drivers, and future prospects. Utilizing data from Kaggle, the notebook performs an in-depth Exploratory Data Analysis (EDA) to uncover trends and insights that have shaped the esports landscape.
GitHub
